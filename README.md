# Dakota Wireless Website

Responsive Dakota Wireless website foundation.

## Current launch mode
The homepage is live in a temporary "Website Under Construction / Coming Soon" state.

## Hosting
Designed for Cloudflare Workers Static Assets with GitHub deployments.

## Files
- `public/index.html` — homepage
- `public/styles.css` — responsive design
- `public/script.js` — mobile navigation
- `wrangler.jsonc` — Cloudflare deployment config
- `package.json` — Wrangler dependency and scripts

## Future expansion
This repository is intended to become the permanent Dakota Wireless website, including wireless plans, devices, Home Internet, customer accounts, online ordering, and POS/back-office integration.
